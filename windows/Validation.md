# Windows 验收记录

本文件集中记录观察结果；组件 README 描述当前行为，不重复维护历史流水账。历史成功不代表随后改动已经实测。

## 用户已确认的功能基线

- 保存的 MSA 密码经服务领取、CP 原生 Negotiate 提交，恢复已有账户和会话；原生 PIN／密码仍可用。
- 一次批准使用后，未重新授权不能再次解锁；重新批准后可以再次解锁。
- 服务和电脑重启使内存批准失效；服务重启后重新批准可使用保存凭据解锁。
- 管理员直接访问密码目录／文件受到 SYSTEM-only ACL 拒绝；正常卸载后查询文件不存在。该观察不证明物理擦除或能够抵御取得 SYSTEM 的管理员。
- 实体机锁屏 BLE 可达，手机签名批准后先后完成手动解锁与自动提交正常路径。
- 安装器正常 Update、重启后更新完成和 Run 自启项注册获用户确认。
- 首次登录无手机磁贴、正常登录后锁屏使用手机解锁符合已确认目标。配对交互获总体反馈，不代替完整配对专项。

## 回归顺序

另行授权构建并部署同一版本后：Update 并重启 → 原生首次登录 → 检查普通用户托盘和 Run → 锁屏按 Enter 发起 → 手机批准后自动解锁 → 核对 SID／session → 无新请求保持锁定 → 新请求再次成功 → 原生登录恢复。随后单独验证服务重启、维护失败及上述负面场景，不连续尝试错误密码。
